How to Access Caterflow MongoDB Data

A brief guide to viewing archived Caterflow data in MongoDB Atlas.

Getting Started

Caterflow keeps a MongoDB database for archived records (the Archive Run History feature). You can view this data directly in MongoDB Atlas, the web dashboard that hosts the database, without needing any technical setup.

1

Log in to MongoDB Atlas

Go to cloud.mongodb.com and choose "Sign in with Google". Use the shared Caterflow Google account:

caterflowadmin@gmail.com

2

Open the Data Explorer

Once logged in, use the link below to go straight to the Caterflow archive collections. This is where you can browse individual records, search, and filter data.

Open Data Explorer ↗
3

Check cluster usage & metrics

From the left-hand sidebar in Atlas, click Metrics (sometimes shown as the cluster name) to see storage used, connections, and read/write activity for the cluster. This is useful for keeping an eye on how much data has built up.

Important: The Data Explorer lets you view and, if you have edit rights, change records directly. Only edit or delete a document here if you are certain what it is — there is no undo. If in doubt, view only, and contact G-Solutions² before making changes.

Finding your way around Atlas

MongoDB Atlas is organized around a few key areas, all reachable from the left-hand sidebar once you're logged in and have selected the Caterflow project/cluster:

  • Database > Browse Collections — same destination as the Data Explorer link above. Each "collection" is a folder of related records (for example, one collection per archived data type). Click a collection to see its documents; click a document to see its full contents.
  • Database > Metrics — cluster health and usage: storage size, number of connections, operations per second. Good for a quick "is everything healthy" check.
  • Charts (if enabled) — lets you build simple visual dashboards from the data without writing any code, useful for reporting.
  • Search bar at the top of a collection view — lets you filter documents using a simple query, e.g. {"status": "completed"} to find only completed records.

Reading a document: Each record ("document") is shown as a set of field/value pairs, similar to a JSON file. You don't need to understand every field — look for the ones with obvious names (like date, status, siteId) to find what you need.

Cluster costs & plans

The Caterflow cluster currently runs on MongoDB Atlas. If usage grows (more storage, more connections, or higher throughput than the current plan allows), Atlas will prompt an upgrade to a paid tier. Pricing is set directly by MongoDB and is separate from any Caterflow development fees — G-Solutions² does not mark this up.
